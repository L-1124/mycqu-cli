# 课表查询时间与学期语义约束 (Schedule Semantics)

## 1. 查询维度与互斥规则

`mycqu schedule list` 支持以下互斥的查询维度：

1. **具体日期查询 (`--date`)**：
   - 取值：严格的 `YYYY-MM-DD` 格式日期（如 `2026-10-19`）。
   - 内部行为：自动将日期映射到所属学期与教学周次，并筛选出该星期几的对应节次课程。
   - **约束**：`--date` 与 `--week` 互斥，严禁同时指定。
2. **教学周查询 (`--week`)**：
   - 取值：`1` ~ `25` 的正整数（如 `--week 8`）。
   - 内部行为：拉取该周从周一到周日的整周排课，按天与节次分组。
   - 可与 `--term` 组合：`--term current --week 8`。
3. **学期查询 (`--term`)**：
   - 取值：`current` 或特定学期整数 ID。
   - 默认值：`current`（当前正在进行的学期）。若未指定周次或日期，返回该学期全量排课。

## 2. 时间与时区标准

- 所有日期均以校区所在地时区 `Asia/Shanghai`（UTC+8）为准。
- 返回的课程信息中，节次（Period）与标准上下课时间对应关系遵循重庆大学作息表：
  - 第 1-2 节：08:30 - 10:05
  - 第 3-4 节：10:25 - 12:00
  - 第 5-6 节：14:00 - 15:35
  - 第 7-8 节：15:55 - 17:30
  - 第 9-11 节：19:00 - 21:25
